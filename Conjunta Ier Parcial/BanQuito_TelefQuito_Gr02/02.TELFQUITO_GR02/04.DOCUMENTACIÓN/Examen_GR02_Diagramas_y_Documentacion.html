1. Diagrama de casos de uso — Módulo de Crédito del Banco BanQuito

El único actor es la Comercializadora de Teléfonos, que consume los servicios web del Banco. Las verificaciones y promedios son pasos incluidos («include») de cada caso de uso.

2. Descripción del caso de uso: Verificar si el cliente es sujeto de crédito

NombreVerificar si el cliente es sujeto de crédito
Servicio webWSSujetoCredito.verifica(cedula) — devuelve el código del cliente si es sujeto de crédito, o 0 si no lo es.
ActorComercializadora de Teléfonos (sistema externo)
ObjetivoDeterminar si una persona puede acceder a crédito directo antes de facturar una venta.
PrecondicionesEl Core de BanQuito está en línea y la comercializadora conoce la cédula del comprador; la forma de pago elegida es «Crédito Directo».
Flujo principal
  1. La comercializadora invoca verifica(cedula).
  2. El sistema comprueba que el solicitante es cliente del banco (cédula registrada en CLIENTE).
  3. Comprueba que posee al menos un depósito (TIPO = DEP) en el último mes.
  4. Comprueba que no es menor de 25 años si su género es masculino.
  5. Comprueba que no tiene un crédito activo (CREDITO.ACTIVO = 1).
  6. Si todas se cumplen, retorna el código del cliente: es sujeto de crédito.
Flujos alternos
  • 2a. No es cliente del banco → retorna 0.
  • 3a. Sin depósitos en el último mes → retorna 0.
  • 4a. Hombre menor de 25 años → retorna 0.
  • 5a. Tiene un crédito activo → retorna 0.
PostcondiciónLa comercializadora recibe el código de cliente y puede consultar el monto máximo (WSMontoMaximo.montoMaximo(codCliente)); si recibe 0 rechaza la venta a crédito.
Regla del monto máximo((Promedio depósitos 3 meses − Promedio retiros 3 meses) × 30%) × 6. La venta se aprueba si el precio del teléfono ≤ monto máximo.

3. Modelo de datos del Core + módulo de crédito (esquema core)

Datos de prueba (03.BDD/01_Core_BanQuito.sql): 6 clientes, 6 cuentas y 54 movimientos (5 depósitos y 4 retiros por cuenta, en los últimos 3 meses). Clientes 1–4: sujetos de crédito. Cliente 5: ya tiene un crédito activo. Cliente 6: hombre menor de 25 años. Las fechas son relativas a la fecha de carga.

4. Diagrama Entidad–Relación de la Comercializadora de Teléfonos

Script: 03.BDD/02_Comercializadora.sql. El pago en efectivo registra un descuento del 42% del precio; el pago con crédito directo no lleva descuento y se factura por el precio completo.
