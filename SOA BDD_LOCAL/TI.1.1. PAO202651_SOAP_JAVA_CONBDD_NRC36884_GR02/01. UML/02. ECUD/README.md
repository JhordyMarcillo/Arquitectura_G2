# 02. ECUD
Especificación de Casos de Uso Detallada de EurekaBank (SOAP Java + MySQL): iniciar sesión, validar token, consultar cuentas, consultar movimientos, registrar depósito, retiro y transferencia (ECUD1 a ECUD7).

Los gráficos de cada caso son los de `03. DIAGRAMAS/01_CASOS_USO` (`ECUD1` … `ECUD7`), y los casos incluidos y extendidos coinciden con el modelo `CU_EUREKABANK.oom`.

Nombre del archivo: `ECUD_SOAP_JAVA_CONBDD_GR02.docx`
