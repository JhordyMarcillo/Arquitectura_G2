# 01. UML

Documentación de análisis y diseño de EurekaBank para TI.1.1.

- `01. ERS`: especificación de requisitos de software.
- `02. ECUD`: especificación de casos de uso detallada.
- `03. DIAGRAMAS`: diagramas UML hechos en PowerDesigner 16.5 (`.oom` editable y `.png` exportado):
  - `01_CASOS_USO`: diagrama general y siete diagramas por caso de uso.
  - `02_ACTIVIDAD`: flujo general y cinco operaciones.
  - `03_SECUENCIA`: siete diagramas de secuencia.
  - `04_CLASES`: cuatro diagramas de clases (servidor y clientes).
  - `05_ARQUITECTURA`: componentes y despliegue.
